# Academic PDF Translation

面向英文科研论文、学位论文章节和工程技术报告的完整简体中文翻译 Skill。它强调全文覆盖、术语一致、技术含义准确，以及公式、图表、引用和参考文献的完整保留。

> 适合需要“完整翻译并形成可交付成果”的学术 PDF；不用于短句、日常文本或只需摘要的翻译任务。

## 主要能力

- 按原文顺序完整翻译，不以摘要或节选替代全文。
- 使用正式、自然的中国大陆学术中文。
- 在全文范围内统一专业术语和缩写。
- 保留数值、单位、变量、希腊字母、上下标、公式及其编号。
- 保留图、表、脚注、交叉引用、引文标记和参考文献编号。
- 翻译可可靠辨认的图题、表题、坐标轴、图例、标注和表格文本。
- 对扫描件和复杂双栏版式进行阅读顺序与 OCR 风险检查。
- 生成 PDF 时进行逐页渲染、内容覆盖和排版质量检查。
- 对无法可靠识别的内容明确标注，不凭空猜测。

## 默认行为

| 项目 | 默认设置 |
| --- | --- |
| 源语言 | 英语 |
| 目标语言 | 简体中文 |
| 文体 | 正式学术中文 |
| 翻译范围 | 完整翻译 |
| 输出模式 | 仅中文，不附英文原段落 |
| 结构 | 保留标题、摘要、关键词、章节、图表、公式、引用、致谢和声明 |
| 专有名称 | 人名、机构、期刊、产品、软件、标准和仪器型号通常保留原文 |
| 参考文献 | 保留完整列表及原始语言，除非用户明确要求翻译 |

仅中文是默认的**内容模式**，不是固定的文件格式。只有在用户要求中文 PDF 时，Skill 才会生成并验证 PDF。双语对照、学习笔记、术语表、参数表和文献综述笔记均需单独提出。

## 安装

### 使用 Skill Installer

在 Codex 中调用 `$skill-installer`，并要求它从本 GitHub 仓库安装 `academic-pdf-translation`。例如：

```text
$skill-installer 请从 https://github.com/sanqiao624/academic-pdf-translation-skill 安装 academic-pdf-translation
```

安装后如果没有立即出现在 Skill 列表中，请重启 Codex。

### 手动安装到用户目录

将整个目录复制到用户级 Skill 目录，并保留目录名和 `SKILL.md`：

```text
~/.agents/skills/academic-pdf-translation/
└── SKILL.md
```

部分现有 Codex 配置使用以下兼容位置：

```text
~/.codex/skills/academic-pdf-translation/
└── SKILL.md
```

### 安装到单个仓库

如果只希望某个项目使用该 Skill，请放入仓库的 `.agents/skills`：

```text
<repository>/.agents/skills/academic-pdf-translation/
└── SKILL.md
```

## 使用方法

在提示词中显式调用 Skill，并附上或指定需要翻译的 PDF：

```text
$academic-pdf-translation
请完整翻译这篇英文论文，输出仅中文 PDF，保留原图、公式、图表编号和参考文献，并在交付前完成逐页检查。
```

双语对照示例：

```text
$academic-pdf-translation
请按“英文原段落在前、中文译文在后”的形式完整翻译，保留全部公式、图表和引用编号。
```

带学习资料的示例：

```text
$academic-pdf-translation
请先完成仅中文全文翻译；翻译正文之后，另附术语表和实验参数表，不要把学习笔记混入译文。
```

当前论文的明确要求始终优先于 Skill 默认设置。

## 工作原则

1. 先检查全文结构、研究主题、方法、变量、图表、公式和参考文献组织。
2. 建立内部全局术语表，确定术语、缩写及其适用语境。
3. 按语义完整的章节或段落组连续翻译。
4. 检查句子覆盖、术语一致性以及数字、单位、符号和引用对应关系。
5. 对全文进行全局审校；如交付 PDF，再进行逐页渲染和视觉检查。

翻译由当前模型完成。OCR、文本提取、版式检查和 PDF 生成工具只能作为辅助，不应用机器翻译服务替代正式翻译，除非用户明确要求。

## 完成标准

只有满足以下条件，任务才应被视为完成：

- 所有要求翻译的正文都有对应译文；
- 技术术语和缩写在全文中保持一致；
- 公式、符号、数字、单位和参考文献保持完整；
- 图表、题注及交叉引用得到保留和正确对应；
- 模糊或无法辨认的内容已明确标记，而非猜测；
- 用户要求的输出文件已经通过内容检查和视觉检查。

## 使用限制

- 复杂公式、双栏排版和低质量扫描件可能需要额外的人工核对。
- 中文重排后的 PDF 页数可能与原文不同，优先保证内容完整和对应关系，而不是强行保持原页码。
- PDF 交付依赖运行环境具备可靠的文本提取、渲染、PDF 生成工具和可嵌入的中文字体。
- Skill 不会绕过论文的访问控制、版权限制或付费墙；使用者应确保拥有处理和翻译源文件的合法权限。
- Skill 不能代替相关领域专家对拟正式发表译文所做的最终审校。

## 贡献

欢迎通过 Issue 或 Pull Request 提交改进建议。建议优先报告可复现的问题，例如术语路由不准确、双栏阅读顺序错误、公式或引用丢失，以及 PDF 排版验证遗漏。

修改 `SKILL.md` 时，请保持以下原则：完整翻译、不擅自总结、术语全局一致、技术信息不失真，并避免加入只适用于单篇论文的规则。
